# Get-AuvikEntityNote

## SYNOPSIS

Read Multiple Entity Notes / Read a Single Entity Note

## SYNTAX

### List (Default)

```
Get-AuvikEntityNote [-FilterEntityId <string>] [-FilterEntityType <string>]
 [-FilterEntityName <string>] [-FilterLastModifiedBy <string>] [-FilterModifiedAfter <datetime>]
 [-Tenants <string[]>] [-PageFirst <long>] [-PageAfter <string>] [-PageLast <long>]
 [-PageBefore <string>] [-AllResults]
```

### ById

```
Get-AuvikEntityNote [-Id] <string>
```

## ALIASES

This cmdlet has the following aliases,
  - Get-AuvikEntity

## DESCRIPTION

Parameter set [ List ] - The Get-AuvikEntityNote cmdlet invokes the GET method of the /inventory/entity/note endpoint (Read Multiple Entity Notes)

Use the Read Multiple Entity Notes API pull information about multiple entity notes.
You'll need the client IDs for the clients you want to run the multiple read against.

Parameter set [ ById ] - The Get-AuvikEntityNote cmdlet invokes the GET method of the /inventory/entity/note/{id} endpoint (Read a Single Entity Note)

Use the Read Single Entity Note API to pull the information about a specific entity note.
You'll need the entity note ID for the specific entity note.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-AuvikEntityNote
```

Returns the result of the /inventory/entity/note endpoint

### EXAMPLE 2

```powershell
Get-AuvikEntityNote -Tenants '1234567890' -PageFirst 10
```

Returns the result of the /inventory/entity/note endpoint limited to the defined tenant

### EXAMPLE 3

```powershell
Get-AuvikEntityNote -AllResults
```

Returns every item from the /inventory/entity/note endpoint by following the pagination links

### EXAMPLE 4

```powershell
Get-AuvikEntityNote -Id '1234567890'
```

Returns the result of the /inventory/entity/note/{id} endpoint
