# Get-AuvikNetworkDetail

## SYNOPSIS

Read Multiple Networks' Details / Read a Single Network's Details

## SYNTAX

### List (Default)

```
Get-AuvikNetworkDetail [-FilterNetworkType <string>] [-FilterScanStatus <string>]
 [-FilterDevices <string[]>] [-FilterModifiedAfter <datetime>] [-FilterScope <string>]
 [-Tenants <string[]>] [-PageFirst <long>] [-PageAfter <string>] [-PageLast <long>]
 [-PageBefore <string>] [-AllResults]
```

### ById

```
Get-AuvikNetworkDetail [-Id] <string>
```

## ALIASES

This cmdlet has the following aliases,
  - None

## DESCRIPTION

Parameter set [ List ] - The Get-AuvikNetworkDetail cmdlet invokes the GET method of the /inventory/network/detail endpoint (Read Multiple Networks' Details)

Use the Read Multiple Networks' Details API to pull extra collected information about the various networks Auvik has discovered not already included in the Network Info API.
You'll need the client IDs for the clients you want to run the multiple read against.

Parameter set [ ById ] - The Get-AuvikNetworkDetail cmdlet invokes the GET method of the /inventory/network/detail/{id} endpoint (Read a Single Network's Details)

Use the Read Single Networks's Details API to pull extra collected information about a specific network Auvik has discovered not already included in the network Info API.
You'll need the network ID for the specific network.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-AuvikNetworkDetail
```

Returns the result of the /inventory/network/detail endpoint

### EXAMPLE 2

```powershell
Get-AuvikNetworkDetail -Tenants '1234567890' -PageFirst 10
```

Returns the result of the /inventory/network/detail endpoint limited to the defined tenant

### EXAMPLE 3

```powershell
Get-AuvikNetworkDetail -AllResults
```

Returns every item from the /inventory/network/detail endpoint by following the pagination links

### EXAMPLE 4

```powershell
Get-AuvikNetworkDetail -Id '1234567890'
```

Returns the result of the /inventory/network/detail/{id} endpoint
