# Remove-AuvikBaseURI

## SYNOPSIS

Removes the Auvik base URI global variable

## SYNTAX

### Destroy (Default)

```
Remove-AuvikBaseURI [-WhatIf] [-Confirm]
```

## ALIASES

This cmdlet has the following aliases,
  - None

## DESCRIPTION

The Remove-AuvikBaseURI cmdlet removes the Auvik base URI global variable

## EXAMPLES

### EXAMPLE 1

```powershell
Remove-AuvikBaseURI
```

Removes the Auvik base URI global variable
